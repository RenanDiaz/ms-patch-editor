# protocol

MS-60B message builders/parsers and patch (de)serialization, ported from
g200kg/zoom-ms-utility (MIT). Ported files must keep the MIT copyright notice;
see `THIRD_PARTY_NOTICES.md`. Message reference: `docs/protocol.md`.

`__fixtures__/` holds **real bytes captured from the pedal** only. Never put
hand-made or fake data there.
